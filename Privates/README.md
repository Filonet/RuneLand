# Privates Plugin

Плагин приватов для PocketMine-MP в стиле "анархия лайт" серверов.

## Особенности

Игроки могут создавать приваты, размещая специальные блоки:

- **Железный блок** - 5×5×5 
- **Золотой блок** - 7×7×7
- **Алмазный блок** - 11×11×11
- **Изумрудный блок** - 21×21×21
- **Незеритовый блок** - 31×31×31

## Зависимости

- **FormAPI** - для создания форм управления приватами

## Управление приватами

При клике правой кнопкой по блоку привата откроется форма управления с опциями:

1. **Информация о привате** - показывает детали
2. **Добавить участника** - добавить игрока в приват
3. **Удалить участника** - удалить игрока из привата  
4. **Список участников** - показать всех участников
5. **Удалить приват** - полное удаление (с подтверждением)

## Управление

Управление приватами происходит **только через формы**:
- Кликните правой кнопкой по центральному блоку привата
- Откроется форма управления (требует FormAPI)
- Выберите нужное действие из меню

### Админские команды

Для администраторов доступна команда `/adminprivates`:
- `/adminprivates cleanup` - очистить висячие приваты
- `/adminprivates debug` - отладочная информация
- `/adminprivates list` - список всех приватов
- `/adminprivates remove <ID>` - удалить приват по ID

## Права доступа

- `privates.use` - использование приватов (по умолчанию: все)
- `privates.admin` - администрирование приватов (по умолчанию: операторы)
- `privates.break` - разрушение приватов (по умолчанию: операторы)

## Защита

Приваты защищают от:
- Размещения/разрушения блоков
- Взаимодействия с блоками и предметами
- Взрывов и огня (настраивается)
- PvP (настраивается)

## Конфигурация

В `config.yml` можно настроить:
- Размеры приватов для каждого типа блока
- Максимальное количество приватов на игрока
- Разрешенные миры
- Настройки защиты (взрывы, PvP, огонь)

## Установка

1. Поместите папку плагина в `plugins/`
2. Убедитесь, что FormAPI установлен
3. Перезапустите сервер

Приваты создаются автоматически при размещении соответствующих блоков!

## Размеры приватов

| Блок | Размер зоны | Описание |
|------|-------------|----------|
| Железный блок | 5×5×5 | Маленький приват |
| Золотой блок | 7×7×7 | Средний приват |
| Алмазный блок | 11×11×11 | Большой приват |
| Изумрудный блок | 21×21×21 | Очень большой приват |
| Незеритовый блок | 31×31×31 | Огромный приват |

## Функции

- **Автоматическое создание приватов** - просто поставьте нужный блок
- **Защита от разрушения** - другие игроки не могут ломать блоки в вашем привате
- **Защита от строительства** - посторонние не могут строить в вашей зоне
- **Система участников** - добавляйте друзей в свой приват
- **Защита от взрывов** - криперы и ТНТ не повредят ваши постройки
- **Защита от огня** - блоки не сгорят в привате
- **Настраиваемое PvP** - можно включить/выключить бои в приватах

## Настройки

Файл `config.yml` позволяет настроить:

- Язык плагина (русский/английский)
- Максимальное количество приватов на игрока
- Интервал автосохранения
- Защиту от взрывов и огня
- Разрешение PvP в приватах
- Размеры приватов для каждого блока
- Разрешенные миры

## Технические детали

- Плагин работает на PocketMine-MP API 3.0.0
- Поддерживает несколько миров
- Данные сохраняются в YAML формате
- Автоматическое сохранение каждые 5 минут
- Проверка на пересечения приватов
